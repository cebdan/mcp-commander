# Сборка и использование MCP Commander

Это отдельное приложение для macOS, написанное на Rust. Оно подключается к Ollama, OpenAI-совместимым API, Anthropic, Gemini и DeepSeek, а также к MCP-серверам локальных программ.

## Установка из DMG

Скачайте DMG для Intel или Apple Silicon со [страницы релиза](https://github.com/cebdan/mcp-commander/releases/tag/v2026.54). Откройте образ и перетащите **MCP Commander.app** на ярлык **Applications** в том же окне. После копирования запускайте приложение из папки «Программы».

## Сборка

Нужны Rust (`cargo`) и инструменты командной строки Xcode. В Terminal:

```bash
git clone https://github.com/cebdan/mcp-commander.git
cd mcp-commander
cargo test --bin mcp-commander
./build-app.sh
open "dist/MCP Commander.app"
```

Скрипт `build-app.sh` собирает release-версию, создаёт `dist/MCP Commander.app` и подписывает приложение локальной подписью. Сборку можно проверить командой:

```bash
codesign --verify --deep --strict "dist/MCP Commander.app"
```

## Провайдер и ключ

1. В разделе **Connections** выберите **Provider to configure**. Для Ollama укажите адрес сервера, например `http://127.0.0.1:11434` для Ollama на этом Mac или адрес своего другого компьютера, затем нажмите **Refresh Ollama model list** и выберите установленную модель в настройках нужной роли.
2. Для DeepSeek используйте `https://api.deepseek.com` и выберите `deepseek-flash` или `deepseek-v4-pro` в настройках роли.
3. Для облачного провайдера вставьте API-ключ, нажмите **Check key**, затем **Save key**. Ключ сохраняется отдельно для каждого провайдера в локальной связке ключей macOS, а не в `config.json`.
4. Кнопка **Delete saved key** удаляет сохранённый ключ.

## Роли и панель исполнителей

- В разделе **Agent roles** включите **Commander mode**. Для **Commander model** выберите провайдера и модель отдельно от исполнителей.
- Кнопкой **Add group** добавляйте группы, кнопкой **Delete** удаляйте ненужные. Для каждой группы независимо выберите провайдера, модель и количество от 1 до 4. Для облачного провайдера сначала сохраните его ключ в **Connections**. Всего возможно до 8 исполнителей; последнюю группу удалить нельзя.
- Напишите задачу командеру. Он может вызвать встроенную команду `delegate_to_implementer` с номером исполнителя и текстом поручения. Несколько независимых поручений могут выполняться одновременно.
- Основная область разделена на две половины: чат командира слева и панель исполнителей справа. В правой половине видны все группы, количество свободных агентов, поручения, состояние и результаты каждого агента.
- Каждый implementer использует модель своей группы, приложенные к текущему сообщению файлы и включённые MCP-серверы. Он не может создавать других агентов. Командер получает результаты исполнителей и формирует итоговый ответ.
- **Stop** прерывает запрос командера и его исполнителей. Уже отправленное действие MCP может завершиться на стороне сервера.
- Выключение **Commander mode** возвращает обычный диалог без делегирования. Настройки ролей сохраняются.

## Сообщения и файлы

- **Enter** отправляет сообщение; **Shift+Enter** вставляет новую строку.
- **Attach files** позволяет выбрать несколько файлов. Перед отправкой они показаны над полем ввода; **Remove** убирает файл из сообщения.
- Поддерживаются UTF-8 текстовые файлы с любым расширением (включая `.md`, `.rs`, `.json`, `.csv` и текстовые файлы GraphCAD), а также PNG, JPEG и WebP. Текстовый файл ограничен 256 КиБ, изображение — 4 МиБ; не более 5 вложений и 8 МиБ изображений в одном сообщении.
- PDF и другие двоичные файлы пока не поддерживаются. Для PDF приложите извлечённый текст или изображения страниц.
- Содержимое вложения передаётся провайдеру командира и провайдеру каждого исполнителя, получившего задачу. Для удалённой Ollama файл отправляется на компьютер с Ollama; для облачной модели — в API её провайдера.
- **Stop** прерывает текущий ответ и дальнейшие шаги агента. Уже отправленная команда MCP может завершиться на стороне сервера.
- **New chat** очищает историю и вложения, ожидающие отправки.

## Подключение GraphCAD через MCP

1. Откройте GraphCAD и включите его MCP-сервер в настройках **AI · MCP**. В примере используется порт `8766`.
2. В MCP Commander нажмите **+** в разделе **MCP servers**. Выберите новый сервер и укажите:
   - **Name:** `graph-cad`
   - **Transport:** `HTTP URL`
   - **Streamable HTTP MCP URL:** `http://127.0.0.1:8766/mcp`
3. Поставьте галочку рядом с сервером и нажмите **Check MCP connections**. Список инструментов появится под кнопкой.
4. Попросите агента выполнить задачу в GraphCAD. По умолчанию каждое действие MCP требует подтверждения. Переключатель **Run MCP tools without asking** разрешает действия включённых серверов без отдельных запросов.
5. Кнопка **Delete** рядом с сервером удаляет его из настроек агента.

Для MCP-сервера, запускаемого командой на этом Mac, выберите **Local command**, введите путь к исполняемому файлу в **Executable or command**, а каждый аргумент — на отдельной строке поля **Arguments**. Эти поля не нужны для HTTP-сервера GraphCAD.

## Если соединение не работает

- `0 tools available`: проверьте галочку сервера, точный URL и то, что MCP-сервер включён в GraphCAD. Выключите или удалите пустые серверы.
- `HTTP 401` при **Check key**: ключ отклонён провайдером. Проверьте ключ и выбранный Endpoint.
- `HTTP 403`: проверьте права доступа ключа.
- `HTTP 404`: проверьте Endpoint и поддержку списка моделей на выбранном сервере.
- Для изображений DeepSeek выберите `deepseek-flash`; `deepseek-v4-pro` не принимает изображения.

Настройки без секретов находятся в `~/Library/Application Support/MCP Commander/config.json`. При первом запуске старые настройки Ollama MCP Agent копируются автоматически; сохранённые ключи продолжают использоваться из macOS Keychain. История переписки хранится только до закрытия приложения.
